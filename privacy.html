Privacy Policy

The Engraved Record · Last updated September 27, 2026

Who we are

The Engraved Record is a YouTube channel (@TheEngravedRecord). This policy covers this website and the channel's private upload tool, "The Engraved Record Uploader".

What the upload tool does

The upload tool uses Google OAuth and the YouTube Data API. It signs in only to The Engraved Record's own YouTube account. It uploads videos, and sets titles, descriptions, tags, thumbnails and privacy status on that account.

The tool is not offered to the public. It does not ask other people to sign in.

What data we use

  • An OAuth access token and refresh token for the channel's own account. They are stored only on the channel owner's computer.
  • Video files and video details that we make ourselves.

We do not collect, store, sell or share personal data from viewers or other YouTube users. We do not use Google user data for advertising.

This website

This website has no forms, no accounts, no cookies of our own and no analytics. It is hosted on GitHub Pages. GitHub may keep standard server logs; see the GitHub Privacy Statement.

Google and YouTube

The tool uses YouTube API Services. By watching our videos you agree to the YouTube Terms of Service. See the Google Privacy Policy. You can remove the tool's access at any time at Google security settings.

Our use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

If this policy changes, we update the date above. For questions, use the contact details on the channel's About page.
